# template-zensical

Template for Entangled/Zensical project

See [entangled.github.io](https://entangled.github.io) for more information on Entangled, and [zensical.org](https://zensical.org) for Zensical.

To use, run

```
entangled new gh:entangled/template-zensical my-new-project
```

Open the README in the generated project for further instructions.
